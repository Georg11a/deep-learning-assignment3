# HW3：整体音量影响从哪里进入模型？

这是可以放进 GitHub 的完整研究包。包含训练代码、配置、特征缓存、听者投票、模型权重、逐条预测、图表与说明；不含原始音频。主要命令与详细目录见 [英文 README](README.md)。

## 两轮研究要分开

**已完成的 HW3 主实验**：注意力没有改善结果 → 2×2 交叉替换提示表示路径的重要性 → 输入中心化 B 显著降低整句增益翻转 → C 用训练时通道丢弃调节增益敏感性。

| 主实验 | 原始测试准确率 | ±6 dB 平均翻转率 |
|---|---:|---:|
| A 原模型 | 54.73% | 30.69% |
| B 中心化两列 | 54.51% | 0.034% |
| C，p=0 | 54.69% | 10.40% |
| C，p=.25 | 55.46% | 1.12% |
| C，p=.5 | 54.35% | 0.34% |
| C，p=.75，验证集选中 | 55.03% | 0.09% |

最可靠的结论是本次固定网格内 p 越大，增益敏感性越低。C 未证明比 B 更准确。λ=0 的解释只限具体模型及验证指标，不代表所有 C 都不需要水平分支。B 是简单有效的增益修正，但仍会稳定地预测错。

**新完成的个人参照研究**：每人固定提供 DFA、TAI、IOM 三条演员标签为中性的注册录音。注册与查询完全分开，所有条件都重新训练；每条件3个种子。D2 只减本人两列幅度均值，D3 再减本人音高均值。D3 是训练前固定的主方案。

| 新研究，同一 1,421 条测试查询 | 按说话人等权准确率 | 按录音准确率 |
|---|---:|---:|
| A，重新训练 | 54.75% | 54.75% |
| B，重新训练 | 54.42% | 54.42% |
| D2，本人幅度参照 | 56.49% | 56.49% |
| D3，本人幅度＋音高参照 | 56.41% | 56.42% |

D3 相对 B：按说话人平均提高1.99个百分点，描述性95%演员bootstrap区间[0.21,3.66]。固定D3模型，把本人参照换成同划分其他演员的参照，五种错配平均准确率降至52.64%；本人匹配的优势为3.78个百分点[2.24,5.34]。结果支持注册匹配有用，但没有分开身份与同会话录音条件。

D3 相对D2只有−0.07个百分点，区间跨零，不能说加音高参照进一步改善。旧测试集曾启发设计，本轮仍是探索性结果。主实验和新研究训练/评分集合不同，不能直接比较两表的准确率。

补充的**事后句子重叠检查**：270条查询与注册录音共享句型但不共享录音；其余1,151条不共享句型。在后者上，D3比B高2.05个百分点[0.35,3.68]，D2高2.46[0.50,4.34]。说明观察到的收益不要求参照里含有同一句话的中性读法；不是证明对训练期间未见措辞的泛化。区间来自本仓库固定种子的5,000次演员配对bootstrap，没有重新训练。

## 一个重要纠正

这次对“注册响度—中性查询悲伤判断”的分析发现：A的相关为−.60，D3为−.17；但听者悲伤投票比例也为−.61，描述性区间[−.82,−.24]。撤回“人没有这种偏差”的说法。也不能把D3相关点估计变小直接说成“消除了刻板印象”。这是18位演员上的相关，可能混有表演与录音差异。**D3的中性→悲伤比例18.43%，与A完全相同，没有下降**；B为20.91%。相关减弱与错误总比例降低是不同问题，且尚未正式检验相关系数差异。

## 个人参照的增益边界

若只给查询加增益而参照保持不变，`(查询＋偏移)－参照`仍保留这个偏移，D2/D3不会像句内中心化那样消去它。若同一增益同时作用于注册与查询，在理想加性特征近似下，两列共同偏移可抵消。这不保证真实特征提取和不同设备下完全不变，也不能直接推出预测翻转率。本轮未新增这两种增益测试；它们是后续验证项目。

报告和视频仍以注意力→2×2→B→C为主线，个人参照只作为简短探索性延伸。`1001_DFA_NEU_XX.wav`和`1002_DFA_NEU_XX.wav`在新实验中是注册录音，不能用来展示D2/D3的评估预测；若用于旧A/B实验演示，需明确标注。

## HW3 之外：探索性后续研究（`research/`）

以下研究在 HW3 实验之后完成，**不属于 HW3 的设计和评分内容**。两者都沿用 HW3 的说话人划分和注册录音；测试说话人已在 HW3 中多次使用，所有结果均为探索性。

- **`research/listener_labels/`**：输入固定为 D2，只改变训练目标（演员标签、听者最高票、听者完整投票分布）。用投票分布训练后，预测明显更接近听者（对投票的交叉熵 2.15 → 1.30），但演员准确率从 56.9% 降到 27.9%，并继承了听者"把轻声说话人的中性听得更悲伤"的倾向。冻结方案在训练前写定，详见其中的 `README-zh.md`。
- **`research/omni_pilot/`**：Qwen2.5-Omni-7B 零样本，给录音附上相对不同参照计算的声学描述。文字描述提高了演员准确率（37.3% → 46.1%），同时让答案偏离听者；音频不变、只把文字中的响度从低改成高，21.8% 的答案改变。个人参照的分档与措辞经过探索性 pilot 修订，最终阈值只由训练集估计，并在报告的运行之前固定。

HW3 与这些后续研究的共同结论：线索和谁比较、模型的判断要符合谁（演员意图还是听者感知），都是会带来可测量后果的设计选择。
