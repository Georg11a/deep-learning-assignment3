# 整体幅度信息应该在模型的哪个位置处理？

*中文版实验文稿。它是可编辑源文件，导出后需要检查1–2页限制。个人参照为另行保存的后续研究。*

## 基线与最初假设

HW2用8段×88维声学特征预测CREMA-D的六类演员意图标签。共享MLP将每段编码为64维表示，按位置拼接后分类；模型不接收转写。64/9/18位演员分别用于训练、验证、测试。三种子使用相同SGD设置、60轮预算，并按验证准确率保留检查点。

最初假设是：自适应注意力池化可以更灵活地聚合情绪相关片段；将两列幅度相关特征在打分路径中中心化，可能减少整体增益影响。评分分支仍接收全部88维，不能说它“只看相对响度”。

## 实验观察与探索性修正

普通注意力准确率从约54.7%降至51.5%，相对打分也没有解决增益敏感性。位置嵌入使准确率恢复至53.1%，但不能据此唯一确定下降原因。

2×2交叉替换分别使用干净/扰动表示与干净/扰动权重。在普通注意力的整句增益正确→错误事件中，只换表示足以出错的比例约83.8%，只换权重约15.8%。它们是可重叠的条件充分性比例，不能当成互斥的原因份额。这个结果促使修正前移：B在编码器之前，对MFCC-0均值与log-RMS均值两列做句内中心化，保留原来的位置拼接读出。

C将这两列的整句均值接入独立2→16→6分支，由相对表示产生门控。训练时以p∈{0,.25,.5,.75}的概率丢弃整条水平贡献，推理时正常打开。该轮运行前保存方案，验证集选中p=.75后才评分测试；但早期测试已启发整体设计，因此仍是探索性后续实验。

## 结果

| 模型 | 原始录音测试准确率 | ±6dB平均预测翻转率 |
|---|---:|---:|
| A原模型 | 54.73% | 30.69% |
| B输入中心化 | 54.51% | 0.034% |
| C p=0 | 54.69% | 10.40% |
| C p=.25 | 55.46% | 1.12% |
| C p=.5 | 54.35% | 0.34% |
| C p=.75，验证选中 | 55.03% | 0.09% |

在本次固定网格内，p控制增益敏感性的规律很清楚，准确率则没有同样规律。选中C比B高0.52个百分点，按演员配对bootstrap的描述性95%区间为[−0.52,1.47]，不能宣称稳定优于B。B是更简单的实际修正，但本轮8,850次比较出现3次翻转，不能再写严格不变或零翻转。

固定相对表示、只沿理论增益方向改变水平输入，得到的C翻转率接近波形测试。两列干预单位不同：±6dB对应原始MFCC-0约±67.88、log-RMS约±0.6908，之后各自除以训练标准差。

将已训练p=.75模型的水平贡献乘以λ=0，验证准确率由59.43%变为59.47%。因此，C与独立训练B的差别不能简单归因于推理时用回了整体水平。p=0的模型关闭分支后总体准确率确实下降，不能把选中模型的观察推广到全部C。高兴类关注来自早期测试，属于探索性分析；选中C的高兴召回在验证集为62.4%，测试仅41.5%。

## 贡献、边界与后续

贡献是针对具体基线比较修正位置，并通过干预区分训练期间可用性和推理期间依赖，而不是发明中心化。注意力失败引出输入修正；复杂C并未证明比简单B更值得使用。

增益测试固定干净裁剪、边界和F0，并避免削波，不能代表所有真实设备或说话人变化。演员意图与听者感知也是不同目标。

另行冻结的个人参照延伸采用每人3条中性注册录音，并在同一剩余查询集合重新训练所有条件。D3按说话人平均准确率56.41%，对比同轮B的54.42%；事后检查1,151条不共享注册句型的查询，仍有+2.05个百分点差异[0.35,3.68]。但D3的中性→悲伤比例18.43%，与A相同、没有下降；听者也呈现响度与悲伤判断的负相关。固定个人参照不能抵消仅施加于查询的增益偏移。本延伸需要额外注册，未分离身份与会话效应，未证明消除刻板印象。完整结果单独保存，不能与上表混算。
