注册使用每人的DFA/TAI/IOM三条中性录音，同句型的其他情绪录音仍可能是查询。这不是把查询录音用于计算参照，但需要排除收益只出现在共享句型的查询上。

当前目录和附件未找到审阅中提及的外部 `sentence_overlap_check.py`，因此独立实现了同名检查：按每位演员的冻结注册清单识别句型，只读取已有测试预测，先在每位演员内平均三个种子，再做5,000次配对演员bootstrap，种子固定为20261108。

## 2. 错误比例与相关性是不同结论

中性→悲伤比例：A=18.43%，B=20.91%，D2=17.60%，D3=18.43%。D3相对A**没有降低这个比例**。D3与注册响度的相关点估计较小，但未正式检验相关系数之差；也不能只通过边际区间重叠决定差异是否成立。

## 3. 撤回“听者没有该关系”

当前正确方向的指标是中性查询上的**悲伤**投票比例，相关为−.61，描述性区间[−.82,−.24]；A的相关约−.60。审阅说明早期看的是愤怒/恐惧/高兴方向，不能支持对悲伤方向的判断。人和模型都出现这一关系，可能反映录音或表演特征，不能直接将其归因于模型刻板印象，更不能认为换成人的标签必然纠偏。

## 4. 增益只作用于查询，还是同时作用于参照

固定参照时，`(x+δ)−r=(x−r)+δ`，不会消去查询新增的幅度偏移。两列输入偏移与A相同不代表两个不同模型的输出翻转率相同。

若查询和所有注册录音接受相同增益，在理想加性特征近似下，`(x+δ)−(r+δ)=x−r`。真实提取中的数值截断、epsilon及其他特征变化使这不是普遍的严格不变性保证。不同设备也不只改变整体增益。README已明确两种未来测试，但没有把分析预期写成已测结果。
